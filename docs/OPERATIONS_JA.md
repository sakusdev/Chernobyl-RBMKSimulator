# RBMK-1000 シミュレーター運転ガイド

> 本シミュレーターは教育・ゲーム用途の簡略モデルです。実機運転、工学解析、安全評価には使用できません。

## 操作席

### 炉主任席

- **制御棒一括挿入**: 値が大きいほど制御棒を深く挿入し、反応度を下げます。
- **AZ-1**: 緩やかな出力低下操作です。
- **AZ-2**: AZ-1より大きな出力低下操作です。
- **AZ-5**: 全制御棒を緊急挿入します。
- **4バンク操作**: 運転支援盤でA〜Dバンクを設定できます。現時点では4値の平均が一括指令へ入ります。

### プラント主任席

- **主循環ポンプ**: 最大8台。運転台数が少ないと設定流量まで上がりません。
- **主循環流量**: 炉心冷却とボイド率に影響します。
- **給水ポンプ**: 最大3台。給水能力の上限を決めます。
- **給水流量**: 気水分離器水位と冷却に影響します。
- **気水分離器水位**: 水位制御の目標値です。
- **タービンバイパス**: 蒸気をタービンから迂回させ、圧力を逃がします。

### タービン主任席

- **タービン調速弁**: タービンへ送る蒸気量を調整します。
- **タービントリップ**: 主蒸気止め弁を閉じ、発電機遮断器を開放します。
- **発電機遮断器**: タービン回転数、周波数、電圧を合わせてから投入します。

## 運転支援盤

画面右端の「運転支援盤」を押すと開きます。

### シナリオ

- **冷態起動準備**: 初期停止状態へ近い操作盤設定。
- **定格運転近傍**: 循環・給水・タービン系を高出力向けに設定。
- **主循環流量低下**: 流量低下によるボイド率と反応度変化を観察。
- **タービントリップ**: タービン停止後の圧力・バイパス挙動を観察。
- **低出力キセノン回復**: 低出力時のキセノン影響を確認。

シナリオは完全な定常状態を直接生成するものではなく、操作盤の目標値を設定します。炉の状態はそこから時間発展します。

### 警報確認

「警報確認」を押すと、現在点灯中の警報が確認済み表示になります。原因が解消すると確認状態も解除されます。

### 状態保存・復元

操作盤のつまみ、ポンプ運転台数、発電機遮断器状態をブラウザのローカルストレージへ保存します。炉心内部の完全な数値状態を保存する機能ではありません。

## 起動の目安

1. 主循環ポンプと給水ポンプを起動する。
2. 主循環流量と気水分離器水位を安定させる。
3. 制御棒を少しずつ引き抜く。
4. 炉周期が急激に短くならないことを確認する。
5. 蒸気発生後、タービン調速弁を徐々に開く。
6. 3000 rpm、50 Hz付近で発電機遮断器を投入する。
7. 蒸気圧力、水位、電気出力を同時に監視する。

## 異常時

- 炉周期が短い、出力が急増、燃料温度が高い場合は制御棒挿入またはAZ-5を検討します。
- タービン過速度、復水器真空低下の場合はタービントリップを使用します。
- 気水分離器水位が低い場合は給水能力と蒸気流量を確認します。
- 主循環流量低下時は、ボイド率増加による正の反応度効果に注意します。
